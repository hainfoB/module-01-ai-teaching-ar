# Séance 01 — Principe CONTEXTE pour l’enseignant

Ce dépôt contient une **page HTML autonome unique** pour la première séance du module 01 : *le principe CONTEXTE dans la rédaction de prompts pédagogiques*.

## Utilisation

Téléchargez le fichier `index.html`, puis ouvrez-le directement dans un navigateur récent. Aucun serveur, package ou installation n’est requis. La page fonctionne hors ligne ; seule l’ouverture de liens externes de référence nécessite une connexion Internet.

## Contenu

La page comprend une séance de 150 minutes, le cadre CONTEXTE, une section sur l’éthique, la confidentialité et les hallucinations, 175 prompts complets disponibles en arabe, français et anglais, une évaluation sommative et un CV/portfolio trilingue.

## Langues

Le sélecteur intégré permet d’afficher l’interface en arabe, français ou anglais. Les prompts sont également accessibles et copiables dans les trois langues.
